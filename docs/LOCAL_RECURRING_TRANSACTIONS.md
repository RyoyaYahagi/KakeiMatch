# 定期収入・定期支出

設定の「定期登録」から、固定金額の収入・支出を登録します。名前、金額、収入または支出に合うカテゴリ、利用中の口座、頻度、開始日、自動登録の有無を指定します。頻度は毎月・毎週・毎年に対応します。一覧から次回日を確認し、詳細から編集・削除できます。

予定の正本は端末内ActualのScheduleです。自動登録は`posts_transaction`へ保存します。カテゴリはScheduleに付属するRuleのカテゴリ設定として保存し、予定と取引を結び付ける`link-schedule`を保持します。KakeiMatch独自のタイマーやCloudflareの定期実行は使いません。

家計簿を開くとActualの予定処理を実行します。端末を閉じている間は記帳されません。次に開いた際の過去の予定日の扱いはActualの仕組みに従います。生成済みの取引は同じ予定として重複生成しません。予定を編集しても、過去に生成された取引の金額・カテゴリは変更しません。予定を削除しても生成済み取引は残します。

自動登録をオフにすると予定だけを保存します。予定から取引を手動で承認する画面、変動金額、複雑な終了条件・休日調整は今回の対象外です。外部で作った未対応の予定は削除できますが、編集できません。

同じ名前の予定の新規作成は拒否します。保存前に操作内容を端末へ記録し、複数タブの保存を排他制御します。途中で失敗した場合は元の操作内容を再試行します。この記録もバックアップに含めます。予定の取引を削除した場合、次回日が削除した取引の日と同じならActualのスキップ機能でその回を進めます。削除の取り消しは元の取引IDを復元します。

検証には合成データを使います。iPhone実機での確認は未実施です。
