# 端末内データの構造変更

KakeiMatchの端末内データは、IndexedDB（ブラウザーの端末内データベース）のバージョンを指定して開きます。移行は同じ更新トランザクション内で行い、失敗した場合はデータと構造の変更をまとめて取り消します。データベースを削除して作り直す復旧処理は行いません。

この文書はIssue #69の実装順に合わせたIssue #53のIndexedDB範囲を扱います。Service Workerの世代別配信と更新手順、Actual依存更新時の互換検証は [アプリ更新](PWA_UPDATES.md) に記載します。iPhone実機確認と破壊的移行前の復旧導線はIssue #53の残作業です。

## バージョンと対応範囲

データベース名は `kakeimatch-local-data` です。構造のバージョンは実装の `LOCAL_DATABASE_VERSION` で管理します。

| 保存済みの構造 | 現行アプリの処理 |
| --- | --- |
| 未作成（更新イベントの旧バージョン0） | レコードと画像・CSV原本の保存領域を作成し、バージョン2までの移行を実行する |
| バージョン1 | 保存済みの行を維持し、原本の所有者を検索するインデックスを追加する |
| バージョン2 | 保存領域・キー・インデックスの構造を確認して開く。移行を繰り返さない |
| バージョン3以上 | 開く要求を拒否し、アプリ更新と再読み込みを案内する。既存データに書き込まない |

バージョン1と2は、レコードと原本の保存領域、各行の `key` と端末内プロフィールを検索するインデックスを持ちます。バージョン2では原本に `[profileId, ownerKind, ownerId]` を検索するインデックスを追加します。保存済みの構造がこの前提と異なる場合は、黙って空の領域を作り直さず、処理を停止します。

データベースの構造バージョンと、バックアップに記載する `LOCAL_DATA_SCHEMA_VERSION` は独立した値です。現時点ではどちらも2ですが、バックアップ形式の移行をデータベース更新の代わりに使いません。今回の変更は保存済みのバージョン2を更新せず、バックアップ形式も変更しません。

## 失敗と別タブの扱い

- 移行手順は `onupgradeneeded` の更新トランザクション内で、旧バージョンを判定して実行します。失敗時にはトランザクションを中断し、行の変更、インデックス、バージョン更新をまとめて取り消します。元の版が残るため、原因の解消後に同じ移行を再試行できます。
- 別タブが古い接続を保持して移行を妨げる場合は、待ち続けず、他の画面を閉じて再読み込みするよう案内します。拒否した開く要求が後から進んだ場合も、移行を中断するか接続を閉じます。
- 開いているデータベースが別タブで更新される場合は、`versionchange` で古い接続を閉じます。その接続で再度操作すると、再読み込みを案内します。自動で接続し直して入力を保存することはしません。
- 未対応の新しい版や想定と異なる構造では、保存済みデータを削除しないよう案内します。起動時もこの理由を表示します。

今後移行手順を増やす場合は、旧版から新版への変更を更新トランザクション内へ追加します。更新中に外部APIや別の非同期処理を待たせません。破壊的なデータ変換が必要になった場合は、この最小範囲の実装だけで安全とみなさず、移行前のバックアップや別領域への読み込みを検討します。

## 自動検証と未確認事項

`src/lib/local-data.test.ts` では合成データを用い、以下を確認します。

- バージョン1から2への移行で複数プロフィールの行と原本が残ること。
- 同じデータベースを閉じて開き直しても、保存済みの内容を読み出せること。
- インデックス作成と行削除の後で故意に移行を失敗させても、版・構造・行・原本が元に戻ること。その後に移行を再試行できること。
- 新しい版、想定外の構造、別タブによる更新待ちを拒否し、既存データを維持すること。
- 別タブの更新後、古い接続からの操作で再読み込みを案内すること。

これはIndexedDBの模擬実装による検証です。世代別Service Workerの更新検証とは別に、iPhoneのホーム画面から起動したPWAの更新経路は未確認です。移行前バックアップの案内、読み取り専用の復旧画面、Actual Budget依存更新時の旧データ互換性確認はIssue #53で継続します。

実装は [local-data.ts](../src/lib/local-data.ts)、起動時の案内は [main.ts](../apps/pwa/src/main.ts) にあります。
