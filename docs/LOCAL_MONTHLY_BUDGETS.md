# 月ごとのカテゴリ予算

設定の「予算設定」から、月と支出カテゴリを選び、円単位の予算を保存します。0円を保存すると、その月のカテゴリ予算を解除します。金額はActualの予算APIへ直接保存し、端末の別の設定として二重管理しません。

ホームの「予算」を開くと、予算対象カテゴリの使用額・予算合計・残額・使用率を確認できます。カテゴリごとの使用額と予算、使用率を棒でも表示します。予算を超えた場合は超過額を文字で示します。ホームの月切替に追従します。

使用額は月次ダッシュボードと同じカテゴリ実績です。品目カテゴリを分けたレシートは子カテゴリへ配分し、振替は含めません。予算のないカテゴリの支出は、予算対象カテゴリの合計に含めません。

非表示カテゴリの保存済み予算も保持します。外部でマイナスに設定された予算は表示しますが、全体の予算合計から除外します。KakeiMatchから保存できる予算は0円以上です。繰越や予算間の資金移動、貯蓄目標はこの画面では扱いません。

合成データのE2Eでは、複数カテゴリの実績、予算超過、月ごとの設定、解除、再読み込みとオフライン編集を確認します。iPhone実機での確認は未実施です。
