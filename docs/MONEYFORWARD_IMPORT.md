# マネーフォワードCSVからの移行

設定の「バックアップと復元」から「マネーフォワードから移行」を開きます。Web版で出力したCSVを端末内で解析し、カテゴリと支払元を確認してから家計簿へ登録します。ログインやAIを使わなくても移行できます。

## 対応形式

UTF-8（BOMあり・なし）とShift_JISに対応します。ファイルは5MB、取引は20,000行までです。列の順序には依存しません。日付、内容、金額（円）、大項目をヘッダー名で識別します。中項目、保有金融機関、メモ、計算対象、振替、IDは任意です。必須列の不足・重複や壊れたCSVは、見つかった列などを表示して停止します。

日付は実在する年月日、金額は正負付きの整数円で検証します。負数は支出、正数は収入です。金額0円や不明なフラグは行番号とエラーを表示します。他の正常な行は取り込めます。

振替は相手口座との組み合わせをCSVから確定できないため、すべて除外します。計算対象がOFFの行も除外します。「現金・カード」は用途カテゴリへ自動変換せず、取り込み前の確認を求めます。ATM引き出しやカード引き落としなど、収支に重ねて入れたくない行は「取り込まない」を選んでください。

## カテゴリと支払元

大項目と中項目、収支区分ごとに件数を表示し、変換先をまとめて指定します。同名カテゴリ、個別の中項目ルール、固定対応表で候補を用意します。既知の変換先が家計簿にない場合は、新規カテゴリの作成候補にします。保存済みの本人の対応は次回も使用できます。

各組み合わせは、既存カテゴリ、新規作成、未分類、除外のいずれかを選べます。自動対応も変更できます。支払元は既存口座、新規作成、未設定から選びます。同名の利用中口座・同じ収支区分のカテゴリは再利用します。未設定の行は「移行元未設定」という口座にまとめます。

未知カテゴリだけは任意で「AIで候補を確認」を使えます。カテゴリ名と選択肢だけをAI APIへ送ります。取引の内容・金額・メモやCSVは送りません。候補は表示するだけで、変換先を確定するのは利用者です。APIを利用できない場合も手動選択で進められます。

## 登録・重複・取り消し

確定前に期間、件数、収支、振替、除外、重複、未解決カテゴリ、新規カテゴリ・口座、数件の変換結果を表示します。CSVのIDを移行元IDとして保持します。IDがない場合は日付・金額・内容・口座・カテゴリ・メモなどの安定したハッシュを使用します。同一の識別子は全口座を通して重複判定し、スキップします。IDのない完全同一取引も重複候補としてスキップするため、実際に複数回の利用がある場合はCSVのID付き出力を使ってください。

品目や画像のない取引として登録し、日付・金額・内容・メモ・カテゴリ・口座を保持します。移行元の大項目・中項目と登録状態は、端末内の移行履歴に残します。CSV原本は保存しません。

移行履歴から今回の移行を取り消せます。登録した取引だけを削除し、重複としてスキップした既存取引は削除しません。移行後の編集も取り消しの対象となります。追加したカテゴリと口座、保存した対応ルールは残ります。途中失敗の再試行と取り消しも履歴から実行できます。

移行履歴と対応ルールは端末内の `app-settings` に保存し、`.kmb`バックアップに含めます。登録前の処理意図と登録後の取引情報を保存し、再読み込み後も再試行・取り消しができます。複数タブでの移行操作はWeb Locksで直列化します。

## 検証

人工CSVを使うパーサー・移行サービスの単体テストと `pnpm --dir apps/pwa test:moneyforward-e2e` で確認します。実取引・実レシートはfixtureに使用しません。
