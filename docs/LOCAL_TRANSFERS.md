# 口座間振替

ホームの「＋記録」から「口座間振替」を選び、日付・振替元口座・振替先口座・金額・任意のメモを入力します。利用中の異なる口座を選んでください。金額は1円以上の整数です。カテゴリは振替には設定しません。

振替はActual Budgetの相互に関連する2取引として端末内に保存します。振替元の残高は減り、振替先の残高は同額増えます。ホームと記録一覧には振替元側だけを表示し、「振替」と明示します。月間支出には加算しません。月次収入・収支とカテゴリ内訳を追加するIssue #70でも、振替を除外する必要があります。

記録一覧の振替を開くと詳細が表示されます。「編集する」から日付・両口座・金額・メモを変更できます。両取引のIDと相互の関連を保ったまま、一括で更新します。Actual 26.9.0の公開 `updateTransaction` は内部更新の完了を待たずに応答するため、振替編集では初期化時に取得する型付きの `transactions-batch-update` 境界を使用します。これはadapter内に限定します。読み直した両取引の日付・金額・口座・メモ・関連を検証してから保存完了を表示します。

入力は端末内の下書きへ保存します。キャンセル・タブ切替・再読込後に入力を再開できます。登録ごとの識別子を保存し、保存結果が不明な場合は同じ内容で再試行します。再試行で振替を追加しません。別のタブで同じ下書きを同時編集することは拒否します。

家計操作にAIアカウントは不要です。振替と下書きは `.kmb` バックアップへ含まれます。復元後も編集できます。

## 検証

合成データを使用するブラウザーテストは次のコマンドで実行します。

```sh
PWA_E2E_URL=http://127.0.0.1:5173 corepack pnpm --dir apps/pwa test:transfers-e2e
```

375 CSS px幅で、異なる口座の検証、下書き保持、登録・両口座変更、一覧の1件表示、月間支出からの除外、再読込、両口座の残高、`.kmb` 復元、オフライン編集を確認します。iPhone実機の追加確認は未実施です。
