# 取引削除と取り消し

取引詳細の「削除する」を選ぶと、削除の確認を表示します。収入、支出、品目カテゴリを分けた支出、口座間振替を削除できます。削除後は記録一覧へ戻ります。「元に戻す」を10秒間表示します。

削除はActualの取引構造全体を対象とします。カテゴリを分けた支出の親・子取引や、振替の対になった取引を一部だけ残しません。取り消しでは元の取引ID、カテゴリ配分、相互の関連、照合状態を復元します。

レシート由来の取引を削除しても、端末に保存したレシート画像、読み取り結果、品目、値引き、カテゴリ情報は保持します。これらの情報は通常の記録一覧から除きます。原本の整理は、設定の端末データ管理で別に行います。

## 途中失敗とバックアップ

削除前に、対象取引を復元できる構造化値と関連レシートを端末の削除履歴へ保存します。Actual側の処理とレシート状態の更新が途中で止まった場合、再起動時に保存済みの操作を再試行します。削除完了済みの履歴から自動復元することはありません。

取り消しは削除後10秒以内に開始してください。開始した取り消しが途中で止まった場合は、10秒を過ぎても再起動時に完了させます。期限後に新しく取り消しを開始することはできません。

`.kmb` は削除状態と履歴を含みます。バックアップ復元後に削除済みの取引を自動で再登録しません。編集や照合の保存結果を確認中の場合、先にその操作を完了してください。処理中の取引は削除を拒否します。

## 確認

合成データによるブラウザーテストでは、確認のキャンセル、収入・支出・分割取引・振替の削除、取り消し、期限経過、原本保持、バックアップ復元を確認します。
