# 記録の検索・絞り込み

「記録」の「検索・絞り込み」から全期間の記録を検索できます。最近の100件だけに限定しません。検索結果は日付の新しい順です。詳細を開いて「検索結果へ戻る」を押すと、適用した条件を保持します。

キーワードは店名・入金元・メモ・レシート品目名の部分一致です。英字の大文字小文字、全角・半角の違いをそろえて比較します。複数の条件はすべて満たす記録だけを表示します。期間の開始日・終了日、金額の下限・上限は指定した値を含みます。

詳細条件には、期間、収入・支出・振替、カテゴリ、口座、金額範囲をまとめます。非表示カテゴリと利用を終了した口座も選べます。適用中の条件を文字で示し、「条件をすべて解除」で一度に解除できます。

品目カテゴリを分けたレシートは、品目のカテゴリでも見つかります。検索結果にはレシート全体を1行で表示します。金額範囲は品目金額ではなく記録全体の金額を使います。振替は出金側を1行で表示し、振替元・振替先のどちらの口座でも見つかります。収入・支出・振替の金額は正の円単位で条件を指定します。

レシート品目名は、現在登録されている確認済みの品目を使います。削除済み取引の原本、未登録のレシート、編集で取り除いた読取結果の品目は検索結果に追加しません。検索は端末内で完結し、外部APIへキーワードを送りません。検索条件の保存機能は今回の対象外です。

検証には合成データを使います。iPhone実機での確認は未実施です。
