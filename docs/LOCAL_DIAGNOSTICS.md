# 端末内の診断

設定の「アプリ情報」から「端末内の診断」を開きます。「診断内容を確認する」で表示を確認してから、その内容をコピーまたはJSONファイルに書き出せます。表示後に別の処理が起きても、コピー・書き出しは確認した内容を使います。最新の結果が必要なら「表示を更新」を押します。オフラインでも表示・書き出しできます。コピーをブラウザーが許可しない場合は書き出しを使います。

## 記録するもの

- Git commitから得たアプリのbuild識別子
- IndexedDBの構造、端末内データ、`.kmb`の形式のバージョン
- オンライン・オフラインの状態
- 起動、保存、AI読み取り、構造の移行、バックアップ、復元、画面処理の結果
- 固定語彙のエラーコードと、発生からの秒数

自由な文字列の情報は取り込みません。店名、品目、金額、カテゴリ、メモ、入力値、実ファイル名、URL、氏名、メール、端末ID、Passkey、token、秘密鍵、生のエラー文、stack trace、AI応答は含めません。既知の処理から渡された固定コードだけを許可し、未知のエラーは `operation_failed` にします。起動時の保存領域の更新失敗は `migration_failed`、対応できない新しい構造は `future_schema` として区別します。

ブラウザー・OSの版は初期版では収集しません。個人識別につながる情報を増やさず、まず処理の種類とアプリの版で障害を見分けます。

## 保存・削除・送信

記録はアプリを開いている間のメモリにだけ置きます。直近15分・最大40件を保持し、古い記録は記録追加や表示更新時に除きます。ページを再読み込みすると消えます。設定の「診断記録を消す」でも削除できます。家計データやお問い合わせ用の別の記録は削除しません。

JSONは厳格なschemaで検証し、未知の項目を拒否します。自動送信、第三者SDK、サーバーへの保存はありません。書き出したファイルは利用者が保存・削除します。コピーや書き出しを行っても、家計データの変更はありません。

お問い合わせに任意で添付するFlight Recorderは別の既存機能です。本機能のJSONを自動添付しません。お問い合わせの同意と保持範囲は [お問い合わせ](CONTACT.md) を参照してください。

## 確認範囲

合成データによるunit testで許可リスト、秘密情報・入力値・未知項目の拒否、件数と保持時間、削除を確認します。375 CSS pxのブラウザーテストでは、オフラインの表示・コピー・書き出し、内容確認後のsnapshot保持、失敗記録と削除、家計データの維持、新しい保存領域構造を拒否した後の診断を確認します。iPhoneの実機確認は別途必要です。

Service Workerに制御されるページが新しい版へ更新される経路は #53 の範囲です。本機能は再読み込み後の前の版の診断を保持しません。成功した復元は再読み込みを伴うため、直前の復元結果も保持しません。失敗した復元の結果は画面を閉じるまで確認できます。
