# 月次ダッシュボード

ホームでは東京の当月を最初に選択し、前月・翌月へ切り替えられます。「当月へ戻る」で現在の月へ戻ります。収入、支出、収支、最近の記録は同じ月を対象にします。最近の記録は新しい順に3件までで、「すべて」から記録一覧へ進めます。端末内の家計簿を読み出すため、通常の閲覧にAIアカウントは必要ありません。

「支出の内訳」では、上位3カテゴリと「その他」を円グラフで示し、凡例にカテゴリ名と割合を書きます。円の中央には最も多いカテゴリと割合を表示します。「すべてのカテゴリ」を開くと、全カテゴリの名前・金額・割合を確認できます。色だけに依存しません。未分類も独立した内訳に含めます。支出がない月は空状態を表示します。

収支は収入から支出を引いた金額です。振替、開始残高、家計外の口座は両方から除きます。カテゴリを分けたレシートは親の総額を一度だけ数え、カテゴリ内訳には品目のカテゴリを使います。非表示にしたカテゴリも過去の支出から消しません。「支出の計算に含めない」と指定した取引は、月の支出・収支・カテゴリ内訳・予算使用額から除きます。記録と口座残高はそのまま保持します。

## 確認

合成データのPWA E2Eでは、収入・支出・振替・複数カテゴリのレシートを登録し、月切替、金額、カテゴリ割合、空状態、オフライン閲覧、画面幅を確認します。iPhone実機での確認は未実施です。

```sh
PWA_E2E_URL=http://127.0.0.1:5173 corepack pnpm --dir apps/pwa test:monthly-dashboard-e2e
```

分割内の正額の調整は、支出カテゴリの金額から引きます。カテゴリの合計が負になる場合は返金・調整として符号を表示し、円グラフは正額のカテゴリだけを対象にします。単独の正額取引は既存の取引種別と同じく収入です。
