# Design

この文書は、本番アプリ `apps/pwa` の見た目の基準です。画面構成と操作は[UX](UX.md)に定めます。

## デザインの目標

KakeiMatchは、家族が毎日開いても疲れない、**明るく親しみやすい生活の道具**を目指します。金融ダッシュボードのような密度の高い画面にはしません。

- 明るい背景に白いセクションを置き、角を丸くして柔らかく見せる
- カテゴリごとに色付きのアイコンを付け、一覧をひと目で区別できるようにする
- 数字は大きく、右に揃えて読みやすくする
- 派手な演出より、読みやすさ、予測しやすさ、操作の少なさを優先する

## 実装の方針

- UIは現行どおり、フレームワークを使わずTypeScriptでDOMを組み立てる。UIフレームワークへの移行はしない
- 色、余白、角丸、文字サイズはすべて `apps/pwa/src/style.css` の `:root` にCSS変数（デザイントークン）として定義する。各画面やTypeScriptに色コードや任意の値を直接書かない
- 繰り返し使う部品（下部ナビ、セクション、1行リスト、状態の表示、ボタン）はクラスと小さなDOMヘルパーにまとめる。同じ役割の部品を画面ごとに作らない
- inline styleは使わない。進み具合の割合など、データで決まる値だけをCSS変数で渡す

## デザイントークン

### 色

意味ごとに名前を付けます。ライトとダークで値を切り替え、名前は共通にします。

| トークン | ライト | ダーク | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#F4F6F5` | `#111715` | 画面の背景 |
| `--surface` | `#FFFFFF` | `#1A2220` | セクション、ナビ、入力欄 |
| `--sunken` | `#EDF1EF` | `#232D2A` | セクション内の小さな面、切り替えの背景、バーの下地 |
| `--text` | `#1C2623` | `#E6EDEA` | 本文 |
| `--muted` | `#56625D` | `#A1ADA8` | 補足、未選択のナビ |
| `--border` | `#E1E7E4` | `#2A3532` | 区切り線、入力欄の枠 |
| `--primary` | `#0B7A68` | `#45C7A8` | 主要ボタン、リンク、選択中 |
| `--on-primary` | `#FFFFFF` | `#062019` | 主要ボタンの文字 |
| `--primary-soft` | `#E4F5EF` | `#173A32` | 選択中の背景 |
| `--success` / `--success-soft` | `#1B7445` / `#E1F3E7` | `#62CF8F` / `#15301F` | 一致、完了 |
| `--warning` / `--warning-soft` | `#8A4F00` / `#FFEFD2` | `#F3B85A` / `#3A2B10` | 要確認、注意 |
| `--danger` / `--danger-soft` | `#B3261E` / `#FDE6E3` | `#FF8F84` / `#3D1C19` | 記録なし、失敗、削除 |
| `--income` | `#1C5FA8` | `#8DB8F5` | 収入の金額 |
| `--scrim` | `rgb(20 28 25 / .45)` | `rgb(0 0 0 / .6)` | シートやダイアログの背後 |

状態と色の対応は固定します。状態は必ず記号と文言も添えます（[UX](UX.md#状態を色だけで伝えない)）。

- 一致 = success
- 要確認 = warning
- 記録なし・失敗 = danger

`*-soft` の背景には、同じ役割の濃い色の文字を載せます。どの組み合わせも4.5:1以上のコントラストを保ってください。トークンを追加・変更する時は、ライトとダークの両方でコントラストを確かめます。

### カテゴリの色

カテゴリのアイコンは、淡い円（`-soft`）に濃い色（前景）の線で描きます。色はカテゴリを区別する補助です。名前は必ず文字で書きます。アイコンの線と背景のコントラストは3:1以上にします。カテゴリの色を文字の色に使わないでください。

| トークン | ライト 前景 / 背景 | ダーク 前景 / 背景 | 初期の割り当て |
| --- | --- | --- | --- |
| `--c-food` | `#D9661F` / `#FFE8D6` | `#FFA766` / `#3B2616` | 食費 |
| `--c-daily` | `#0B7A68` / `#E4F5EF` | `#45C7A8` / `#173A32` | 日用品 |
| `--c-transport` | `#2D66B5` / `#E0EBFA` | `#8DB8F5` / `#182A44` | 交通 |
| `--c-fun` | `#B23C74` / `#FBE2EE` | `#F28DBC` / `#3A1A2B` | 娯楽、衣服 |
| `--c-util` | `#946600` / `#FFF1C7` | `#F0C150` / `#3A2E0E` | 水道・光熱 |
| `--c-comm` | `#6450BF` / `#ECE8FB` | `#B3A5F5` / `#241F45` | 通信、医療 |
| `--c-other` | `#5E6A65` / `#E8ECEA` | `#A9B4AF` / `#262E2B` | その他、振替 |

利用者が追加したカテゴリには、この7色を順に割り当てます。円グラフの「その他」は `--c-other` を薄く表示します。

### 文字

フォントは端末の標準フォントを使います。Webフォントは読み込みません。

```css
font-family: -apple-system, BlinkMacSystemFont, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic UI", system-ui, sans-serif;
```

| 役割 | サイズ / 太さ | 使う場所 |
| --- | --- | --- |
| 大きな金額 | 32〜36 px / 700 | ホームの今月の支出、入力中の金額 |
| 画面の見出し | 22 px / 700 | タブの画面名 |
| 選択画面の見出し | 22 px / 700 | 記録の種類を選ぶ画面 |
| 小見出し・上部バー | 16〜17 px / 700 | セクションの見出し、作業画面の上部 |
| 本文・行の主な文字 | 16 px / 400〜500 | 店名、入力値、ボタン |
| 補足 | 13〜14 px / 400〜500 | 行の補足、ラベル、日付の見出し |
| ナビのラベル | 12 px / 400（選択中は700） | 下部ナビだけ |

- 金額には `font-variant-numeric: tabular-nums` を付け、桁を揃える
- 金額の記号は、支出に「−」（U+2212）、収入に「+」を使う
- 見出しの段階は3つまでにする。太さだけで多くの段階を作らない
- 行の高さは本文で1.5を基準にする

### 余白

4 pxの倍数の段階だけを使います。

| トークン | 値 | 主な用途 |
| --- | --- | --- |
| `--space-1` | 4 px | アイコンと文字の間 |
| `--space-2` | 8 px | ボタン同士、行内の要素の間 |
| `--space-3` | 12 px | 行のアイコンと文字の間、セクション同士 |
| `--space-4` | 16 px | 画面の左右の余白、セクションの内側 |
| `--space-5` | 20 px | 大きなセクションの内側 |
| `--space-6` | 24 px | 画面内の大きな区切り |
| `--space-8` | 32 px | 画面下部の余白 |

画面の左右の余白は16 pxです。iPhoneの切り欠きとホームバーには `env(safe-area-inset-*)` を足します。

### 角丸と影

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 10 px | 小さなアイコンの背景、切り替えの中のボタン |
| `--radius-md` | 12 px | 入力欄、収入・収支の小さな面 |
| `--radius-lg` | 16 px | 主要ボタン、件数の枠、警告の帯、カテゴリのボタン |
| `--radius-xl` | 20 px | セクション |
| `--radius-sheet` | 24 px | 下から出るシートの上の角 |
| `--radius-full` | 999 px | 丸いアイコン、日付のボタン、バッジ |

影はライトだけでごく弱く付けます（`--shadow: 0 1px 3px rgb(28 38 35 / .06)`）。ダークでは影を付けず、面の明るさの差で区別します。中央の「＋追加」ボタンにだけ、浮いて見える影を付けます。

## 部品

`components/` のようなディレクトリは作りません。部品はCSSのクラスと、`apps/pwa/src` の小さなDOMヘルパーで表します。部品には家計の知識を持たせません。家計の意味を持つ組み立て（記録の行、照合の行など）は各画面のモジュールに置きます。

### アプリの枠と下部ナビ

- 本文の最大幅は640 px。画面の上部にアプリ名や説明文を常に出さない
- 下部ナビの高さは、ホームバーの余白を含めて84 pxを目安にする
- 各タブはアイコン（24 px）とラベル（12 px）を縦に並べる
- 中央の「＋追加」は直径56 pxの円で、`--primary` で塗る。ナビの上へはみ出させ、下のラベルの高さは他のタブと揃える
- 照合のバッジは、`--warning` の背景に `--surface` 色の数字を載せる

### セクション

`--surface` の面に `--radius-xl` の角丸を付け、関係する行をまとめます。中の行は区切り線で分けます。1件ごとにカードを作りません。

### 1行リスト

```text
[アイコン 36px]  店名（16px・500）            −¥3,284（16px・700）
                 補足（13px・muted）
```

- 行の高さは最小60 px（設定の行は56 px）。行全体をタップできるようにする
- 長い店名は1行で省略記号にする。補足は1行にまとめる
- 詳細へ進む行には右端に「›」を付ける

### 状態の表示

- **件数の枠**（照合の上部）：`*-soft` の背景に、記号・状態名・件数を縦に並べる
- **警告の帯**（ホーム、要確認の詳細）：`--warning-soft` の背景に、記号、太字の要点、補足の文を並べる
- **行の補足**：記号と短い文を、状態の色で書く（例：「△ 金額が¥50違います」）
- **バッジ**：数字だけを出す場合は、読み上げ名に意味を含める

### ボタン

| 種類 | 見た目 | 使う場所 |
| --- | --- | --- |
| 主要 | `--primary` で塗る。高さ52 px、横幅いっぱい、`--radius-lg` | 1画面に1つ（登録する、同じ支出として処理） |
| 補助 | `--surface` の面に `--border` の枠 | 明細を取り込む、日付の選択 |
| 文字 | 背景なしで `--primary` の文字 | 戻る、すべて、別の支出です |
| 破壊的 | `--danger` の文字。塗らない | 削除する |

作業画面の主要ボタンは、画面下の固定の帯（`--surface`、上に区切り線）に置きます。

### 入力

- ラベルは入力欄の上に置き、13〜14 pxの `--muted` で書く
- 入力欄は高さ48 px、`--radius-md`、`--border` の枠。フォーカス時は `--primary` の2 pxの枠にする
- 金額の入力欄は高さ64 px、数字を32 pxの太字にし、先頭に「¥」を置く
- 数値には `inputmode="numeric"`、日付には `type="date"` を使う
- 入力のエラーは、その欄のすぐ下に `--danger` の文字で表示する

### 選択

- **切り替え**（記録の種類の絞り込み）：`--sunken` の下地に、選択中だけ `--surface` の面を載せる
- **日付のボタン**：丸いボタン。選択中は `--primary-soft` の背景、`--primary` の2 pxの枠と文字にする
- **カテゴリのボタン**：4列、高さ68 px。色付きのアイコンの下に名前（2行まで）を書く。選択中は2 pxの `--primary` の枠、`--primary-soft` の背景、太字にする。読み上げでは単一選択のラジオボタン（`role="radiogroup"` / `role="radio"`、`aria-checked`）として扱う。値は隠した選択欄（select）が持ち、ボタンはその値を書き換える

選択中であることは、色だけでなく枠・✓・`aria-pressed` でも示します。

### シートとダイアログ

- ＋追加は画面下から出るシート（`<dialog>` を `showModal()` で開く）にする。上部につまみ、見出し、閉じるボタンを置く。開く時に下から0.2秒でせり出し、つまみや見出しを下へ80 px以上動かすと閉じる
- カテゴリ・口座の途中追加は、中央の小さなダイアログにする
- どちらも背後を `--scrim` で暗くし、フォーカスを中に閉じ込める

### 円グラフ（支出の内訳）

- ドーナツ型、直径128 px、線の太さはその約11%。区分の間に2 pxのすき間を空ける
- 区分は最大4つ（上位3カテゴリとその他）。12時の位置から時計回りに大きい順で並べる
- 中央に最も多いカテゴリの名前（2行まで）と割合を書く
- 右側の凡例に、色の点・カテゴリ名（2行まで）・割合を書く。区分の色は重ならないように選ぶ
- 読み上げ用に、全体の内訳を文にした `aria-label` を付ける

### 進み具合のバー

高さ10 px、`--sunken` の下地に `--primary` で塗ります。予算を超えた時は `--danger` にし、「¥3,000超過」のように文字でも示します。

## アイコン

- 24 pxの格子に描いた線のアイコンをinline SVGで使う。線の太さは2 px、端と角は丸くする。色は `currentColor` にする
- 絵文字をアイコンとして使わない
- アイコンだけで意味を伝えない。文字を添えるか、読み上げ名を付ける
- 同じ意味には同じアイコンを使う（例：要確認は三角、記録なしは丸に「!」、一致はチェック）

### ホーム画面のアイコン

「カードとレシート」の案Bを採用します。クリーム色（`#FFF3DD`）の地に、緑のカードと白いレシートを重ね、レシートに緑のチェックを描きます。

- iOS用に180×180 pxのPNG（`apple-touch-icon`）を用意する。iOSはSVGのアイコンを安定して表示しないため
- manifestには192 px、512 px、`purpose: "maskable"` の512 pxを用意する。maskable版は、絵柄を中央80%の安全域に収める
- `theme-color` は、ライトとダークでそれぞれの `--bg` に合わせる

## ダークモード

- 端末の外観設定（`prefers-color-scheme`）に合わせて自動で切り替える。アプリ内に切り替えの設定は置かない
- 切り替えはトークンの値の差し替えだけで行う。画面ごとにダーク用のCSSを書かない
- 写真やレシートの画像は暗くしない

## レスポンシブ

スマートフォンを基準にします。デスクトップでは本文を最大640 pxで中央に置きます。一覧と詳細を左右に並べる2ペイン表示は、必要になった時に検討します。

## 動き

アニメーションは、状態の理解を助ける時だけ200 ms程度で使います。

- シートの出入り
- 詳細の開閉
- 保存完了の表示
- 読み取り中や取り込み中の表示

装飾のための長い演出は使いません。`prefers-reduced-motion` が有効な時は止めます。

## 禁止事項

- 1件ごとのカード、同じ情報の重複表示
- 色コードや任意の余白の直接指定
- inline styleの乱用
- 同じ役割のボタンや入力欄を複数の実装で作ること
- hoverに頼る操作
- 44 CSS pxより小さいタップ領域
- 絵文字のアイコン、アイコンだけのボタンに読み上げ名がないこと
- AIが出した値を、確認なしに正しいものとして見せること

## デザインを決める順序

1. 情報の構造
2. 利用の流れ
3. ワイヤーフレーム（[UX](UX.md)）
4. 部品の構成
5. 文字と余白
6. 意味の色
7. 細かな装飾

見た目を磨く前に、主な利用者が迷わず操作できるかを確かめます。
