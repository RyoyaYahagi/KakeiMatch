# 口座残高

設定の「支払元」から、利用中の口座と現在残高を一覧で確認できます。負の残高は「−」を付けて表示します。利用終了の口座は別の折りたたみ一覧に表示します。

口座を選び「口座の記録を見る」を開くと、その口座の収入・支出・振替を日付順に確認できます。取引を選ぶと通常の詳細画面へ移動します。

残高は端末内Actualのaccount balance APIを正本にします。未来の日付の取引は現在残高に含めません。振替はそれぞれの口座の残高へ反映されます。月次収支には含めません。

合成データのE2Eで負残高、振替による残高変化、利用終了の口座、口座別記録、reloadとオフライン閲覧を確認します。iPhone実機は未検証です。
